# Apple Game

**The worms attack!**

**!! Work in Progress !!**

This is a **sidescrolling platformer** where you play as an apple named Appy, platforming to save the fruit world from the evil worms!

It is a prototype for a larger game, currently only containing the tutorial. I have used **Unity** and **VSCodium** to create this platformer. Almost all of the code is written using **C#**. All of the sprites I made are drawn using **Aseprite**, however most of the sprites currently consist of basic shapes.

I made this project because I simply thought it was a pretty silly idea. Platformers are one of my favourite genres (tied with Psychological Horror) and I thought that a game where you play as a fruit attacked by worms could be fun. 

No demo *yet*, however there will be one when the project is shipped.

### Play

If you really wish to run it, here's an installation guide (from source):

1. Install Unity Hub and Unity 6000.6.3f1 (This is the version I used)
2. Run `git clone https://github.com/Stampest26/apple-game.git` (Clones the project to your system)
3. Add the project to Unity Hub (Add > Add Project From Disk > Select Folder)
4. Launch the project (This might take a little while on the first open)
5. Open `Assets/Scenes/Tutorial` and press Play!

**Troubleshooting**: Check the Unity console for errors, in this case it's probably my fault

### Controls

- **A**/**D** (WASD movement) or **arrow left** and **arrow right** to move
- **Space** to jump
- **J** to take out the Mud Launcher
- **K** to take out the Sucker
- **Left click** to use the selected tool
